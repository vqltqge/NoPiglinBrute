# No Piglin Brutes

No Piglin Brutes is a simple Minecraft plugin that disables Piglin Brutes.

The plugin removes Piglin Brutes whenever a chunk containing them is loaded. This means that Piglin Brutes spawned using commands or spawn eggs will also disappear after the chunk is unloaded and loaded again.

## Commands

### `/disablebrutes <true/false>`

Enables or disables Piglin Brute removal.

- `/disablebrutes true` — Piglin Brutes will be removed.
- `/disablebrutes false` — Piglin Brutes will remain normally.

## Config

Alternatively, Piglin Brute removal can be enabled or disabled in `config.yml`:

```yaml
brutes-disabled: true
```
